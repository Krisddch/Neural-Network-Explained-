# Neural Network Explanation

Лендінг для презентації: як нейронна мережа бачить рукописну цифру. Анімований скрол з паралакс-ефектом, усе намальовано на `<canvas>` (без зображень).

Відкрийте `index.html` у браузері.

## Інтерактивна частина

У кінці сторінки можна намалювати цифру мишкою чи пальцем, і мережа спробує її розпізнати. Це мережа 784 → 16 → 16 → 10 із сигмоїдою. Ваги взяті з [3b1b/videos](https://github.com/3b1b/videos/tree/master/_2017/nn) (`pretrained_weights_and_biases`) і дотреновані на MNIST з аугментаціями та синтетичними «одиничками», намальованими як на сторінці. Ваги вбудовані в сторінку як JSON, обчислення йдуть прямо в браузері.
